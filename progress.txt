# PDFCraft Build Progress

## Project Info
- **Name:** PDFCraft
- **Description:** PDF generation SaaS with AI-powered template creation
- **Started:** 2025-01-30
- **Method:** Ralph Autonomous Development Loop

## MCP Servers Available
- `supabase` - Database, auth, storage
- `vercel` - Deployment, env vars
- `stripe` - Products, prices, subscriptions

## Key Decisions
- Using Next.js 14 App Router
- Supabase for auth and database
- Puppeteer for PDF generation
- Claude API for AI template generation
- Stripe for payments

### Iteration 3 - story-003

**Status:** ✅ Complete

- Restricted to application/pdf mime type only
- Created 5 storage policies for access control

**Storage Policies:**
- Users can upload to own folder (INSERT) - user_id/* path
- Users can read own files (SELECT) - user_id/* path

### Iteration 13 - story-013
**Story:** API Authentication Middleware
**Status:** ✅ Complete

**What Was Done:**
- Created lib/api/auth.ts with validateApiKey function
- Extracts Bearer token from Authorization header
- Hashes key with SHA-256 and compares to stored hash
- Returns userId and apiKeyId if valid
- Updates last_used_at asynchronously
- Returns 401 with clear error codes if invalid
- Checks revoked_at before allowing access

**Files Created:**
- src/lib/api/auth.ts

**Error Codes:**
- MISSING_API_KEY: No Authorization header
- INVALID_API_KEY_FORMAT: Key doesn't match expected format
- INVALID_API_KEY: Key not found in database
- API_KEY_REVOKED: Key has been revoked

### Iteration 15 - story-015
**Story:** PDF Generation API Endpoint
**Status:** ✅ Complete

**What Was Done:**
- Created POST /api/v1/generate endpoint
- Authenticates using validateApiKey
- Validates body with Zod (html or url required)
- Checks usage limits before generation
- Generates PDF using Puppeteer
- Uploads to Supabase Storage (pdfs bucket)
- Creates generation record with status tracking
- Returns generation_id, url, size_bytes, duration_ms
- Increments credits_used on success
- Error responses: 400 (validation), 401 (auth), 402 (limit), 500 (server)

**Files Created:**

**API Response:**

```json
  "data": {

    "size_bytes": 12345,

}
```
